# Floor and Ceil in a Sorted Array

## Problem Statement

You're given a sorted array `a` of `n` integers and an integer `x`.

Find the floor and ceiling of `x` in `a[0..n-1]`.

### Note

-   Floor of `x` is the largest element in the array which is smaller
    than or equal to `x`.
-   Ceiling of `x` is the smallest element in the array greater than or
    equal to `x`.

------------------------------------------------------------------------

## Example

**Input:** `n=6, x=5, a=[3, 4, 7, 8, 8, 10]`

**Output:**

``` text
4 7
```

------------------------------------------------------------------------

-   `1 <= a[i] <= 10^9`
