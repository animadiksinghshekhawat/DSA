# Count Subarrays with Given XOR

> **Platform:** Code360 (Coding Ninjas)  
> **Difficulty:** Medium  
> **Topic:** Prefix XOR, Hash Map

## 🔗 Problem Link

https://www.naukri.com/code360/problems/count-subarrays-with-given-xor_1115652

---

# 📝 Problem Statement

Given an array of integers **`ARR`** and an integer **`X`**, find the number of subarrays whose **bitwise XOR** is equal to **`X`**.

> **Note:**  
> A subarray is obtained by removing zero or more elements from the beginning and/or the end of the array.

---

# 📥 Input Format

- The first line contains an integer **`T`** denoting the number of test cases.
- For each test case:
  - The first line contains two integers **`N`** and **`X`**.
  - The second line contains **`N`** space-separated integers representing the array.

# 📤 Output Format

For each test case, print the number of subarrays having XOR equal to **`X`**.

> **Note:** You don't need to print anything in the function.

---

# 📌 Constraints

- `1 ≤ T ≤ 10`
- `3 ≤ N ≤ 5 × 10^4`
- `0 ≤ X ≤ 10^9`
- `0 ≤ ARR[i] ≤ 10^9`

**Time Limit:** `1 second`
